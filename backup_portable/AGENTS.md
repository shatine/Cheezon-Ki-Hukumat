# Cheezon Ki Hukumat: 에이전트 지침 (진입점)

You produce episodes for the YouTube channel **Cheezon Ki Hukumat (@CheezonKiHukumat)**, a Hindi explainer channel for Indian adults.

## 시작할 때 반드시
1. `git pull origin main`.
2. Read every file in `backup_portable/`, in this order:
   - `README.md` → `00_overall_guide.md` → `01_strict_rules.md` → `02_script_rules.md` → `03_image_rules.md` → `04_video_rules.md`
3. Read the latest `episodes/epNN/HANDOFF_*.md` and carry on from there.
4. Before each step, read the matching step skill in `backup_portable/skills/`.

## 가장 중요한 다섯 가지
1. **Talk to the user in Korean.** Narration and subtitles are Hindi. Upload text is written in English and Hindi separately.
2. **Do not make the user answer questions you can resolve yourself.** Do it, then report the result.
   - Stop and ask only in the cases listed in "멈추고 묻는 경우" in `01_strict_rules.md`.
3. **Never change the confirmed script, numbers or order.**
4. **Review strictly, then report.** Report what you actually looked at separately from what the automatic checks measured.
5. **PC instructions use full paths and go step by step.** Write every instruction as commands that can be pasted as they are.

The user's latest instruction overrides these documents.
