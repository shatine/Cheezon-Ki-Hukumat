# 9편 참고 영상 분석

2026-10-27. 아래는 **실제로 읽은 자막 또는 확인한 표본 프레임**의 분석이다. 자막을 읽는 것은 전체 영상·소리·모든 프레임을 검수한 것과 다르다. 영상 속 숫자와 공법은 `research/evidence.md`에서 별도 검증했다.

## 1. Ronnie & Barty — 대중의 생활 질문

[원영상](https://www.youtube.com/watch?v=uS89-Gos32M), 1,180,100회, 약9:50. 공개 자동 자막 전체 열람. 분석 시점은 자막 기준 근사치다.

1. 약0:06, 친구에게 어디 가는지 묻는 일상 대화에서 시작한다.
2. 약1:36, 지역 주민에게 개통이 큰 변화라는 의미를 붙인다.
3. 약3:50, 터널 길이·상부 덕트·하부 비상통로를 짧게 설명한다.
4. 약4:10, 구조 소개에서 생필품을 사러 오갈 수 있다는 생활효과로 옮겨 간다.
5. 약6:53, 출구를 통과하며 반대편 풍경을 드러낸다.
6. 약7:31 이후, 통행 체험과 관광·겨울 접근성의 변화를 이야기한다.
7. 약8:54 이후, 지역의 미래는 아직 전망이라는 태도로 끝낸다.

- **훅:** 지역 주민의 자연스러운 대화와 당일 왕복이라는 생활 변화.
- **비교:** 예전 우회로와 새 길. 촬영 당시 통과 시간·속도를 일반 규정으로 쓰지 않는다.
- **원리 설명:** 설비를 소개하지만 구조·역학을 깊게 설명하는 영상은 아니다.
- **우리 적용:** S03–04에서 “왜 이 길이 필요한가”를 짧고 구체적으로 설명한다. 결말은 현재의 통행 장면으로 돌아간다.
- **해석 한계:** 이 훅이 높은 조회수의 원인이라는 인과관계는 확인하지 않았다.

## 2. Tech Travel Eat — 눈과 터널의 시각 대비

[원영상](https://www.youtube.com/watch?v=m9euztsdEIo), 1,469,216회, 약30:53. 말라얄람어 원영상의 자동 자막이 힌디어로 잘못 인식되어 대사·전체 정보 순서 분석에는 쓰지 않았다.

실제 플레이어에서 확인한 표본: 0:15 입구·진행자와 눈 / 5:00·10:00 터널 주행 / 15:00 차량 내부 / 20:00·25:00 폭설 속 외부 도로·포털 / 30:00 진행자 마무리.

- **확인한 시각 구조:** 눈 내리는 바깥 → 밝은 내부 주행 → 눈 덮인 외부. 이는 표본 사이의 모든 장면을 확인했다는 뜻은 아니다.
- **우리 적용:** 겨울 고개와 터널이라는 대비만 사용한다. 터널이 모든 연결도로의 눈 문제를 해결한다고 표현하지 않는다.
- **미확인:** 정확한 도입 대사·비유·전체 내레이션 흐름. 자막 전문 분석 완료로 처리하지 않는다.

## 3. Gaurav Kapoor Vlogs — 짧은 반응과 출구 공개

[원영상](https://www.youtube.com/watch?v=9ZpfA85Sals), 1,710,387회, 약13:10. 공개 자동 자막 전체 열람. 인식 오류가 많아 명확한 구간만 참고했다.

도입의 친구들 농담 → 약2:31 터널 진입 → 약2:55 출구 뒤 풍경 반응 → 약5:34 폭포 → 약8:08 도로 풍경과 반응 → 약11:32 귀환 일정 → 구독 안내.

- **훅:** 익숙한 동행자들의 편한 대화.
- **원리 설명:** 공학 과정보다 여행 체험 중심. 기술 설명의 핵심 참고로 선정하지 않는다.
- **우리 적용:** 통행·출구를 보고 느끼는 놀라움만 기능적으로 참고한다. 친구들의 대사나 긴 잡담은 가져오지 않는다.

## 4. Build India — 원리 설명의 핵심 구조 참고

[원영상](https://www.youtube.com/watch?v=Twrfo4eoqco), 50,054회, 약13:47. 공개 자동 영어 자막 전체 열람. **백만 조회 조건과 별도의 기술 구조 참고**다.

약0:03 발파 훅 → 1:07 로탕 지형·겨울 단절 → 2:26 우회로와 터널의 이동시간 대비 → 3:09–5:31 계획·정치·연혁 → 5:45 공법 → 6:45 물 유입과 지연 → 7:28 도로 단면 → 8:38 관제 → 9:25 바닥 아래 대피로 → 10:37 전략·생활효과 → 13:29 CTA.

- **훅:** 강한 공사 동작과 지역의 길 문제를 연결한다.
- **참고할 순서:** 필요성 → 실제 난관 → 단면과 해결 → 완성된 길의 의미.
- **이번 변형:** 긴 정치·연혁 구간은 뺀다. 물과 약한 지반의 난관을 앞당기고, 선행 강관·즉시 지보·바닥 폐합·배수의 인과를 더 자세히 설명한다. 화재·환기·대피로는 별도 장으로 확장하지 않는다.
- **숫자 주의:** 자동 자막의 Austria/Australia와 난구간 길이·연수 등 오인식 가능성이 있다. 이 영상의 수치를 그대로 옮기지 않았다.

## 5. AFCONS — 실제 시공 장면의 보조 자료

[원영상](https://www.youtube.com/watch?v=NgioFN4sCwE), 242,962회, 약3:43, 완공 전 영상. 공개 설명문과 플레이어의 표본 프레임 12개를 확인했다. 자막은 없다.

확인 범위: 초기 제원·남쪽 포털·경로 대비·공사 인력·군용 차량·지하 천공 장비·높은 눈벽과 입구. 시공의 규모와 접근 제약을 이해하는 보조 자료다. 정확한 작업 순서를 프레임 표본만으로 복원하거나, 초기 제원을 준공값으로 쓰지 않는다.

## 우리 대본에 적용한 세 가지

1. **생활 동기를 짧게:** 겨울에 막히는 고개가 왜 산속의 어려운 공사를 감수할 이유인지 먼저 설명.
2. **난관을 앞당기고 답은 단계별로:** 물과 토사 → 물만 빼도 남는 지반 → 선행 보강 → 짧은 굴착 → 닫힌 받침 → 배수·계측.
3. **첫 장면 회수:** 주행 영상으로 시작하고, 그 빈 공간을 어떻게 확보·유지했는지 이해한 뒤 같은 통행 장면으로 끝냄.

## 수집·사용 범위

yt-dlp 자막 다운로드는 HTTP 429로 실패했다. 대체로 실제 YouTube의 공개 ‘스크립트 표시’ UI를 읽었다. 유료 전사·유료 API는 사용하지 않았다. 원본 영상·전체 자막을 결과물로 복제하지 않고 URL·자체 요약·열람 한계를 제공한다. 3편의 100만 조회 여부는 확인했으나 그중 한 편의 전체 대사 분석은 불가능했다는 제한을 유지한다.
