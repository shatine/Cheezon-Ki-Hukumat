# 9편 힌디어 대응 검토

2026-10-27. 한국어 확정본 S01–S24는 변경하지 않았다. `script_lock.json`의 본문 해시로 보존 상태를 확인한다.

## 실제 대조

- 승인 한국어를 문장 단위로 나눠 **78행**의 힌디어와 한국어 직역을 만들었다. 앞선 작업 중 81행이라고 집계했던 수치는 최종 원문 대조에서 정정했다. 원문 문장 누락은 없다.
- 1차 번역 후 다른 구간의 번역자가 원문과 다시 대조했다. 최대·약·미만·조건부 가능성, 시공사·정부·발주기관 귀속, 2024년 기록의 과거 시점을 보존했다.
- S12d의 연결 문법만 자연스럽게 고쳤다. 한국어 본문·주장·숫자·순서는 바꾸지 않았다.
- 첫 질문은 S01a·S13b·S22b에 같은 힌디어를 사용한다. 썸네일 질문도 이 문구를 사용한다: `जिस पहाड़ से पानी उमड़ रहा था, उसमें सुरंग कैसे बनाई गई?`
- `lines_hi_ko.tsv`의 한국어는 힌디어 직역이다. 승인 원문은 별도의 `source_ko_sentences.json`에 보존했다.

## 자동 확인

문장 ID·순서·개수, 힌디어 내 아라비아 숫자·라틴 문자·한글 유무, 질문 반복의 일치, CTA 문구, 원문 본문 해시를 검사한다. 자동 결과는 `validation_translation.json`에 기록한다. 자동 검사는 의미의 자연스러움이나 실제 음성 발음을 보증하지 않는다.

## TTS 확인 범위

- 기존 무료 로컬 Voice Studio·charonclone 기준 파일·seed7·speed1.0을 사용한다.
- 기존 ASR 정규화는 `नौ दशमलव शून्य दो`를 `9.0`과 `2`로 갈라 해석할 수 있어, 에피소드 실행기에서 이 정확한 낭독형을 `9.02`로 정규화한다. `9.2`를 허용하는 규칙은 넣지 않는다.
- 자동 받아쓰기 불합격을 임의로 통과 처리하지 않는다. 청취·불량 처리 결과는 생성 후 별도 기록한다.
