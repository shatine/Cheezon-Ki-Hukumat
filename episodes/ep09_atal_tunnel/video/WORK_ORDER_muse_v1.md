## 4. 추후 승인 뒤 한 개씩 생성하는 순서

1. 해당 ID의 `image`에 기록된 실제 선택 PNG를 첨부한다. 텍스트만으로 시작하지 않는다.
2. 해당 ID의 영어 `prompt`를 그대로 넣고 한 번만 제출한다.
3. 30~60초 간격을 두고 완료 여부를 한 번 확인한다. 제출을 연속으로 누르지 않는다.
4. 완료 후 다운로드하여 정확한 `save` 경로에 둔다. 읽히는 글자/워터마크, 어두워짐, 실사↔3D 교체, 모양 변화, 카메라 회전처럼 명백한 불량을 확인한다.
5. 다음 ID로 진행한다. 재시도는 같은 방법으로 무작정 반복하지 않고 원인을 기록한다. 최대 2회 재생성 기준을 따른다.
6. 첫 프레임 첨부가 거부되면 같은 그림으로 한 번 재시도하고, 다시 거부되면 `거부`로 기록한다. 텍스트 전용 생성으로 바꾸지 않는다.

## 5. 실제 생성 뒤 검수와 계획 갱신

- 원본 영상은 PC에 보존한다. 실측 검수를 위해 ffprobe로 실제 길이·해상도·fps를 기록한다.
- 각 영상의 **1초 간격 프레임 시트**와 **0.5초 간격 평균 밝기**를 만든다. 이 자동 결과와 사람이 실제 본 결과를 분리한다.
- 모든 프레임에서 첫 프레임 형상/색/단계, 물·입자 방향, 바닥/배수 경로 분리, 글자·워터마크, 갑작스러운 무빙, 인물 크기, 밝기 변화를 확인한다. 밝기 하락 15 이상은 경고로 확인한다.
- `video/review_clips_v1.md`에 ID별 실제 선택 파일, 실제 길이, 합격/보류/탈락, `USE` 시작·끝, 이유와 다음 방법을 기록한다.
- `USE` 끝은 **실제 길이−0.05초 이내**다. 10초 제작 요구 사양을 실측 합격 구간처럼 복사하지 않는다.
- 확정된 실측 `USE`를 계획에 넣고 모든 자동 점검 오류가 0인지 다시 확인한다. 소스가 부족하면 새로 필요한 컷을 준비한다. 감속·끝 프레임 정지·동일 구간 반복·역재생으로 채우지 않는다.
- Flow 영상은 유료 예외다. 별도 사용자 지시 없이 전환하지 않는다. 재생성 비용이나 유료 작업을 이번 준비에 승인된 것으로 간주하지 않는다.
- 미디어 공유가 필요하면 해당 단계의 교환 절차를 따르되, 원본은 PC에 계속 보존한다. 생성/검수 보고서와 실제 `USE`는 저장소에 남긴다. 최종 미디어를 저장소에 영구 축적하지 않는다.
