# 9편 서사·시각 증명 설계

상태: 한국어 검수 전. **시간표·컷 계획이 아니다.** TTS 실측 전에는 시작·끝 시각이나 컷 길이를 배정하지 않는다.

## 중심 설계

- 첫 장면: 밝은 산악 지대의 완성된 터널 입구와 통행 차량.
- 모순: 지금 차가 지나는 빈 공간에, 공사 중에는 물과 흙·돌이 함께 밀려들었다.
- 걸린 것: 겨울 길의 단절, 굴착 공간을 지키는 문제.
- 중심 질문 Q0: **물이 쏟아지는 산을 어떻게 뚫었을까?**
- 답의 방향: 물을 처리하면서, 지반을 먼저 보강하고 짧게 파자마자 받친다.
- 놀라움: 천장만 아니라 바닥까지 받침을 닫아야 한다. 물도 모두 봉쇄하면 끝나는 문제가 아니다.
- 마지막 장면: 차량이 달리는 같은 길을 다시 보여주고, 보이지 않는 지보·배수의 역할을 회수한다.

## 질문과 증명

| 질문 | 문단 | 답 / 다음 제약 | 보여줄 증명 | 근거 |
|---|---|---|---|---|
| Q0 물이 쏟아지는 산을 어떻게 뚫었나? | S01–02 | 최대 유입·짧은 난구간을 제시 | 완성 차도와 공사 개념 단면 대비 | E1/E3/E4/E5 |
| Q1 왜 이 산을 뚫어야 하나? | S03–04 | 겨울 고개를 피한다 → 산속 지질은 다른 문제 | 기존 고갯길/터널 우회 경로를 편집 도형으로 비교 | E2 |
| Q2 펌프로 물만 빼면 되나? | S05–06 | 느슨한 지반도 받쳐야 한다 | 물과 작은 입자가 함께 유입되는 단면 | E4/E6 |
| Q3 안 판 천장을 어떻게 받치나? | S07–10 | 선행 강관·짧은 굴착·즉시 지보 → 바닥도 약함 | 진행 방향 종단면→강관 위치→지보 설치 단계 | E6/E7 |
| Q4 천장을 받치면 끝인가? | S11–13 | 바닥까지 이어 닫힌 받침 → 물은 남음 | 임시 상부 폐합과 최종 깊은 인버트를 따로 표시 | E8 |
| Q5 물은 어디로 가야 하나? | S14–16 | 차수·배수 조합, 막힌 뒤 수두 문제 | 물길/방수층/배수 경로, 차도와 구분 | E9 |
| Q6 같은 방법으로 계속 파나? | S17–19 | 계측·시행착오·보강 변경 | 변형을 읽고 지보를 바꾸는 개념 도식 | E10 |
| Q0 첫 질문 회수 | S20–24 | 관통→개통→남는 관리→동사형 답 | 처음의 완성 차도와 보이지 않는 구조 재결합 | E11/E12 |

## 구조 참고의 적용

| 참고 기능 | 이번 대응 | 시각적 증명 | 적용 판단 |
|---|---|---|---|
| 익숙한 대상에서 모순 발견 | 여행객이 지나는 터널 vs 굴착면 유입 | 같은 시설의 현재/개념 공사 장면 | 채택 |
| 더 쉬운 답의 실제 한계 | 펌프로 물만 빼도 느슨한 지반은 남음 | 물만 제거한 상태에서 지반의 별도 역할 | 채택. 펌프 자체가 무용하다고 말하지 않음 |
| 준비→짧은 작동→고정→반복 | 선행 강관→굴착→지보→다음 전진 | 전체/종단/단면을 구분 | 크레인 구조 모델의 기능을 변형 적용 |
| 한 물질의 경로 따라가기 | 물이 들어오는 곳→모이는 곳→빠져나가는 곳 | 고정 단면에 유로를 순차 강조 | 하수처리 모델의 기능만 적용. 공정 사실은 인도 현장 원문으로 검증 |
| 첫 풍경 재해석 | 차도는 계속 지켜 내는 빈 공간 | 첫 입구·통행 장면 회수 | 채택 |
| 별도 설비·역사 목록 | 환기·화재·기록 순위·정치 연혁 | — | 중심 질문과 직접 연결되지 않아 생략 |

이는 기능의 재설계다. 참고 채널의 문장·고유 비유·장면을 번역하거나 복제하지 않는다. 같은 주제 영상에서 실제 관찰한 내용은 `../refs_analysis.md`에 별도로 남긴다.

## 다음 제작 단계에 넘길 시각 규칙

1. 실제 지층·수로를 단순화한 **설명용 개념도**라는 상태를 명시한다. 정확한 시공 도면으로 소개하지 않는다.
2. 주인공 형상: 하나의 양방향 2차로 터널. 평행한 차량용 터널 두 개로 만들지 않는다.
3. 같은 단면에서 굴착 진행 방향을 유지한다. 물 유입은 파랑·흰 흐름, 토사 혼합은 회갈색 입자, 지보·강관은 고정된 형상으로 구분한다.
4. 파이프 루프는 진행 방향 위쪽에 들어간다. 곧은 강관 여러 개가 천장 둘레에 아치 모양으로 배치된다. 강관 자체가 휜 아치이거나 천장 안쪽의 기둥처럼 보이면 안 된다.
5. 임시 인버트·깊은 인버트·차도 아래 대피로는 다른 대상이다. 상부 굴착 중 임시 바닥 폐합과 나중의 아래쪽 굴착·깊은 최종 인버트를 단계별 도식으로 분리한다. 최종 바닥 구조까지 난구간의 약4년 상부 굴착 기간에 완료됐다는 시각 순서를 만들지 않는다. 이번 본문에 없는 대피로를 배수관처럼 그리지 않는다.
6. 원리 영상은 고정 카메라. 고체의 붕괴·유동을 과장해 생성하기보다 단계별 고정 도형과 색·화살표를 편집으로 강조한다.
7. 생성 이미지에는 숫자·글자·로고·번호판을 넣지 않는다. 실제 기술자·정치인·어린이를 재연하지 않는다.
8. 도입은 향후 실측 30초 구간에 긴 자연스러운 영상 3–5개를 배정한다. 현재는 네 가지 증명 장면(통행/공사 유입/지반 단면/새 길의 규모)만 후보로 두며 시각은 미배정이다.
9. 실제 이미지·영상 프롬프트와 최종 컷 계획은 대본 확정 및 `narr_timing.json` 확보 뒤 작성한다.
