# 9편 이미지 제작 명세 v1

2026-10-27. 승인 대본 78문장과 실측 79컷에 대응하는 **생성 그림** 명세다. 마스터 6장·영상 첫 프레임 50장·정지 그림 29장으로 구성한다. 현장 사진이나 실측 설계도 복제가 아니며, 실제 기록 사진으로 소개하지 않는다. 기준 형상의 출처와 실제 확인 범위는 `reference_brief.md`에 있다.

## 기준 그림

장면에서 필요한 기준만 생성한다. 마스터도 무료 Flow에서 한 장씩 만들고 원본 크기로 검수한 뒤 프로젝트 미디어에 올린다. 아래 ID는 외부 사진 파일명이 아니라 새로 생성할 기준 그림 ID다.

| ID | 표현과 고정 관계 | 사용 경계 |
|---|---|---|
| AT_S | 남측 실제 입구의 관찰 형상에 근거한 실사풍 재구성: 숲이 있는 계곡, 노랑·주황 세로 외장, 갈색 사선 차양 아래 사각 도로 개구부, 회색 보강 사면 | 별도 전통 장식 접근문을 합치지 않는다. 북측 박공지붕을 섞지 않는다 |
| AT_N | 북측 입구의 관찰 형상에 근거한 실사풍 재구성: 진녹색 큰 박공, 작은 적갈색 박공, 황색 벽, 사진 오른쪽 사각 개구부, 회색 옹벽, 암석·눈 | 남측 수목·외장으로 바꾸지 않는다. 기준 사진 좌우를 지리적 동서로 해석하지 않는다 |
| AT_C | 승인 대본에 근거한 공사 장면의 실사풍 재구성: 약한 지반, 상부 굴착, 회색 강철 지보와 숏크리트, 작은 노란 장비, 중립 백색 작업등 | 실제 어느 시점의 보존 사진이라고 설명하지 않는다. 작업자의 얼굴은 작고 등·옆모습만 보인다 |
| AT_INT | 완공 터널 내부의 실사풍 개념 재구성: 단일 튜브 양방향 두 차로, 밝은 중립 회색 벽, 평평한 차도 | 본 표본에서 확인하지 못한 내부 마감색·설비 배치를 정확한 현장 고유값으로 주장하지 않는다 |
| G3D_EXC | 밝은 3D 굴착 원리 모형: 화면 왼쪽은 이미 굴착한 공간, 오른쪽은 앞으로 팔 지반. 진행축은 왼쪽→오른쪽. 천장 강관은 축 방향으로 곧게 뻗고 횡단면에서 아치형으로 배열 | 지반은 회갈색, 지보는 회색, 선행 강관은 청록, 설명용 주입재는 보라. 실제 재료 고유색을 주장하지 않는다. 물은 파랑·토사 혼합은 회갈색 |
| G3D_DEEP | 같은 좌표·색을 쓰는 **후속 단계** 모형: 남은 하부 굴착을 마친 뒤 난구간의 깊은 곡선형 최종 인버트가 위·양옆과 닫힌 링을 이루고 평평한 차도는 안에 놓임 | 상부 굴착 중 임시 바닥 폐합과 동시에 같은 부재로 그리지 않는다. 일반 본선 모든 구간이 이 단면이라는 뜻도 아니다 |

## 공통 표현

- 실사 장면에는 3D 기준 그림을 첨부하지 않는다. 기준 대상의 정체·기본 재료색·방향·단일 차량 터널 관계를 유지한다. 파생 첫 이미지는 승인 대본과 해당 장면 명세에 적힌 공정·보강 상태를 구성하므로, 추가 강관열 등 명시된 부재가 마스터보다 더 있을 수 있다. 각 첫 프레임이 선택된 뒤에는 그 부재 개수와 형상을 영상 내내 유지한다.
- 실사 마스터는 대상 형상만 참조한다. 실제 장면은 카메라 위치·촬영 거리·초점 대상을 바꿔 마스터 구도를 복사하지 않는다.
- 3D 원리 첫 프레임은 고정 카메라 구도다. 선택된 첫 프레임 이후의 원리 영상 43개는 고체뿐 아니라 물·주입재의 위치·양·경계·형상도 고정하고, 기존 표면과 경로의 빛·색·기존 화살표 발광만 바꾼다. 영상 안에서 부재를 추가하거나 굴착·주입·변형·물 높이 변화로 공정을 진행시키지 않는다. 단계가 다른 첫 이미지를 제작하는 것과 한 영상 안에서 상태를 바꾸는 것은 구분한다.
- 강관 지붕은 앞으로 팔 짧은 구간의 천장 위 지반을 보강한다. 터널 전장을 한꺼번에 덮는 강철 지붕으로 만들지 않는다.
- 축 방향 강관과 횡단면 방향 강철 지보를 서로 다른 부재로 읽히게 한다. 강관을 아치형으로 굽히지 않는다.
- S11의 약한 받침 바닥은 일반 원리 설명이다. 현장에서 실제 바닥이 솟는 장면이나 관찰하지 않은 붕괴 형태를 발명하지 않는다.
- S15의 막힌 물길은 **위험을 설명하는 가상 원리 상태**다. 실제로 주요 수로를 모두 막았다는 장면으로 제시하지 않는다. 물은 파랑, 물이 누르는 힘은 주황 화살표로 구조 쪽을 향하게 한다.
- S16의 배수 경로는 구조 뒤 물을 별도 관·배수구로 모아 바깥으로 연결한다. 물을 차도로 붓거나 대피 통로 안에 흘리지 않는다. 물길이 막힌 채 배수 성공처럼 그리지 않는다.
- S17 계측 장비는 관찰·판단 도구다. 센서가 스스로 땅을 고정하거나 붕괴를 막는 시각 효과를 넣지 않는다.
- S18 손상·변형은 현장 기록을 설명하는 단순화 재구성이다. 정확한 사고 장면, 피해자나 실제 작업자를 재현하지 않는다.
- S19 상부 통과와 후속 하부·최종 바닥 작업은 분리된 단계다. 약 4년을 완공 전체 소요 기간으로 시각화하지 않는다.
- S21의 후속 누수 언급은 2024년 기술자의 설명에 귀속한다. 지금 전체 차도가 침수됐다는 장면을 만들지 않는다. 날짜·귀속은 편집 오버레이로만 넣는다.
- 지도·거리·수치·날짜·핵심 질문·구독 문구는 생성 그림에 쓰지 않는다. 정확한 숫자와 힌디어는 편집에서 얹는다.

## 생성 순서와 점검

`make_prompts_v1.py`는 `plan/scene_catalog_v1.json`의 모든 자산을 읽고 마스터 의존성을 먼저 배치한다. 최종 컷 자산 ID가 없는 상태에는 전체 프롬프트 완료로 판정하지 않는다. 프롬프트 JSON은 한 장씩 그대로 붙여 넣으며, `ref`의 모든 기준 그림을 순서대로 첨부한다. 첨부 거부 시 텍스트만으로 진행하지 않는다.

원본은 PC `img_raw`, 워터마크 제거본은 `img`에 `v1_{id}_{n}.png`로 저장한다. 이 명세의 프롬프트 검사는 텍스트·자산 대응·참조 의존성만 검사했다. 실제 생성·다운로드·시각 검수 상태는 `picks_v1.md`에서 별도로 기록한다. 생성 후 밝기·해상도·인접 컷 유사도 자동 측정과 별도로 모든 원본을 실제로 보고 형상·접합·화살표·글자·얼굴·구도를 검수한다.
