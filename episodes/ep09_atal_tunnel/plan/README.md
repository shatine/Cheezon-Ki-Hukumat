# 9편 컷 계획 실행

`plan_v1.py`는 `review_edit/narr_timing.json`의 **완료된 실제 TTS 시간표**와 `narr_check.json`의 78문장 합격 기록만 읽는다. 시간표가 없거나 문장이 누락되면 종료하며 추정값으로 대체하지 않는다. 확정 한국어 본문 해시와 문장 순서도 확인한다.

10초는 현재 계획에 명시할 **영상 제작 요구 사양**이다. 최신 Muse 설정을 직접 확인했다는 뜻이 아니다. 생성 전 현재 설정을 확인하고, 생성 뒤 1초 간격 화면·0.5초 간격 밝기를 검수해 실제 `USE` 구간을 정한 다음 계획을 갱신해야 한다.

저장소에 파일을 반영한 뒤 PowerShell에서 실행한다.

```powershell
python 'D:\youtube\Cheezon-Ki-Hukumat\episodes\ep09_atal_tunnel\plan\plan_v1.py' --clip-seconds 10
```

`--clip-seconds` 또는 `CHEEZON_CLIP_SECONDS`는 필수다. 값이 없으면 실행하지 않는다. 매체 원본의 끝 0.05초를 비우며 실제 컷은 30fps 정수 프레임으로 배정한다. 소스 속도는 1.0배속이고 감속·정지 프레임 연장·반복·역재생은 사용하지 않는다.

출력:

- `shot_list_v1.json`: 편집기가 읽을 컷·프레임·소스 경로.
- `shot_table_v1.md`: 문장 대응과 읽기 쉬운 컷 표.
- `scene_catalog_v1.json`, `scene_catalog_v1.md`: 각 소스의 문장 ID, 화면 의미, 원리 여부, 기준 그룹, 동작·카메라.
- `source_registry_v1.json`: 계획에 사용한 `VID`, `IMG`, `SEG` 등록부. 모든 등록 소스를 한 번씩 사용한다.
- `plan_validation_v1.json`: 계획 자동 검사와 실제 미디어 검사의 범위를 구별한 결과.

원리 49문장은 고정 카메라의 원리 영상으로 전 구간 배정한다. 관련 질문·명명 문장도 같은 공정 블록에 넣는다. 상부 임시 바닥 폐합과 후속 깊은 최종 인버트는 장면 블록을 분리한다. 도입 30초는 5초 이상 영상 3~5개, 나머지 비원리 시간의 약 15%는 관통·누수 점검의 동작 영상, 나머지는 2~4초 이미지로 배정한다.

**자동 검사 통과는 등록된 소스와 계획 논리 검증에 한정한다.** 이 단계에서는 미디어를 생성하지 않았고 실제 파일의 존재·길이·형상·글자·밝기·동작을 통과했다고 보고하지 않는다. 프롬프트의 기준 그림과 실제 생성본 검수는 후속 단계다.
