# 채널 화면 스타일

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

스타일은 질문의 기능에 따라 고른다. 상황·피해·규모는 자연색의 선명한 실사풍, 내부 원인은 밝은 3D 단면·분해·흐름 도해다. 실사 90% 같은 목표나 모든 장면 회색 클레이 원칙을 두지 않는다.
같은 대상 기준 그림과 구조를 고정한다. 인물은 인도 성인, 얼굴 작게. 생성 그림의 글자·숫자는 편집으로 처리한다. 사고·불편을 무조건 상징으로만 대체하지 않는다.
장치 동작의 순서·유체 방향·힘 전달은 실제 근거와 일치해야 한다. 이미지→영상의 형태 변화가 원리를 바꾸면 적합한 결과가 아니다.
Grok/Flow를 선택한 작업에 한해서만 [과거 UI 관찰](refs/browser-operations-history.md)을 참고한다. 과거 비용·승인 대화·계정 정보를 현재 실행 권한으로 해석하지 않는다. 최신 사용자 지정 도구를 우선하며 Muse와 Flow 계정을 섞지 않는다.
