# Cheezon 영상 — 질문을 화면의 변화로 설명한다

> **최우선 (2026-10-22):** 새 편은 [제작 공정](references/production-process.md)을 처음부터 끝까지 따른다. 이 공정의 화면 규칙이 아래 일부 문구보다 우선한다. 3D 원리는 영상, 나머지 장면은 10~20%만 영상이고 나머지는 이미지에 효과를 넣는다. 감속, 정지, 반복 금지는 그대로다.

프로젝트의 `D:/youtube/7. Cheezon Ki Hukumat/CHANNEL.md`와 해당 에피소드의 확정 대본·제작 기록을 먼저 읽는다. 이 스킬은 기존 영상 제작 스킬의 현재 Cheezon 진입점이다. 다른 채널의 기본값이나 과거 예시로 현재 설정을 덮지 않는다.

## 보팔 제작에서 반영한 실행 기준
새 편의 음성·장면 계획·생성·편집·검수·업로드 자료를 만들 때 [보팔 제작 개선](references/bhopal-production-lessons.md)의 해당 단계를 읽고 적용한다. 음성 실측 후 장면 계획, 문장 경계와 영상 경계 분리, 연속 소스 프레임 배정, 원리를 바꾸는 생성 오류 제외, 검수 화면의 문장별 대응, 영어/힌디어 납품 분리를 포함한다. 보팔의 컷 수·총 길이를 다음 편의 목표값으로 복사하지 않는다.

## 원문과 제작 단계
한국어 검수 완료본을 고정한다. 힌디어·음성·자막·장면은 같은 정보와 순서를 전달하며 길이는 실제 낭독을 따른다. 6분 상한을 적용하거나 재미를 이유로 원문을 바꾸지 않는다.
현재 요청의 승인 범위를 이어받는다. 이미지 검수 후 영상 생성 지시가 있으면 해당 검수를 거친다. 이미 승인된 작업을 다시 묻지 않으며 스킬 수정·후보 보관만으로 생성·게시를 시작하지 않는다.

## 질문을 증명하는 장면 계획
새 기획에는 [문제와 질문 연결](references/curiosity.md)을, 장면·프롬프트·편집에는 [장면 인계와 검수](references/shot-plan.md)를 읽는다.
첫 장면은 제목이 약속한 문제·모순·불편을 보여준다. 분위기용 항공샷을 먼저 늘어놓지 않는다.
실사/실사풍은 상황·규모·결과를, 단면·분해·흐름 도해는 보이지 않는 원인을 담당한다. 실사와 3D의 비율을 고정하지 않고 모든 핵심 원리가 화면에 드러나는지 확인한다.
한 장치의 부품 위치·입출구·색 의미·흐름 방향을 고정한다. 정확한 설명은 검증 가능한 모델·레이어·편집 그래픽으로 통제하며 생성 모델의 임의 변형을 원리로 채택하지 않는다.

## 생성과 카메라
이야기 장면은 밝고 자연색이 선명한 인도 현장감, 원리 장면은 밝고 구분하기 쉬운 3D/도해로 만든다. 긴장감은 낮은 노출이나 세피아가 아니라 상황·변화·결과로 만든다.
프롬프트는 장면/동작과 카메라를 분리한다: `Movement / Speed / Framing / End`. 클립당 하나의 안정된 무빙 또는 고정 카메라를 쓴다. 핵심 대상은 가운데 70%, 아래 15%는 자막 가독성을 고려한다.
원리 장면은 카메라가 고정돼도 된다. 물·밸브·힘·균열 등 설명 대상의 변화가 보여야 한다. 카메라 이동은 물리적 변화의 대체물이 아니다.
이미지→영상은 검수된 기준 그림을 활용한다. 최신 사용자가 지정한 도구를 따른다. 이 프로젝트의 최근 경로는 직접 이미지 생성과 Muse 영상 생성이며, Flow/Grok/Veo로 자동 전환하거나 계정·프로필을 섞지 않는다.
생성 플랫폼의 현재 UI·모델·비용·잔액을 확인한다. 과거 가격·한도·셀렉터는 현재 사실이 아니다. 타임아웃 후 기존 결과를 확인하고 중복 제출을 피한다.
사고·불편·오염은 설명에 필요한 범위에서 직접 보여주되, 실제 증거와 재현을 구분한다. 거절을 속여 우회하지 않고 허용되는 묘사·도해로 설계를 바꾼다. 뒤늦은 모자이크가 플랫폼 적합성을 보장하지 않는다.

## 편집과 완료
핵심 원리 문장에 그 움직임이 있는 클립을 배치한다. 관련 없는 B-roll, 같은 동작의 무의미한 재사용·역재생·루프로 길이를 채우지 않는다.
대체로 짧고 다양한 컷을 쓰되 도해를 읽을 시간과 필요한 쉼을 확보한다. 실제 낭독을 과속·삭제하지 않는다. 정밀 도해까지 강제 줌인하지 않는다.
숫자·라벨·화살표는 검증된 위치에 편집으로 넣는다. 숫자 강조는 노란 테두리, 힌디어 자막은 데바나가리 지원 폰트와 ASS Spacing 0을 쓴다.
첫·중간·끝 상태와 컷 연결을 확인한다. 대본 대응, 원리 정확성, 대상 일관성, 반복·튀는 연결, 자막·소리, 파일 전체 디코드를 검수한다. 자동 통과와 실제 장면 관찰·사람 청취를 구분한다.
최종 납품은 기본 1920×1080/30fps이며 원본 생성 해상도를 별도로 기록한다. 승인 범위에 편집·자막·캡컷·업로드 자료가 포함되면 해당 결과까지 이어간다. 게시와 썸네일 생성은 별도 실제 요청 범위를 따른다.

## 반드시 하지 말아야 할 것 — 장면 분량 부족 재발 방지 (2026-10-19)
- 음성과 장면표의 전체 시간 합계가 같다는 이유만으로 이미지·영상 분량이 충분하다거나 생성 준비가 끝났다고 판단·보고하지 않는다. 이미지 수, 장면 수, 실제 사용할 움직이는 영상 길이를 각각 검증한다.
- 10초를 넘는 설명 구간에 이미지 한 장 또는 짧은 영상 한 개만 배정하고 완료 처리하지 않는다. 대사 속 대상·작동·결과의 변화에 따라 구도와 상태를 나누고, 각 구간에 필요한 이미지·영상·원리 애니메이션을 구체적으로 확보한다. 10초 이하도 내용 변화와 사용 가능한 영상 길이가 맞는지 점검한다.
- 부족한 길이를 정지 유지, 마지막 프레임 동결, 반복·역재생, 의미 없는 슬로모션, 동일 그림 확대만으로 메우지 않는다. 같은 장면을 오래 정지시킨 뒤 짧게 움직이고 전환하는 편집도 금지한다.
- 영상 부족을 해결하려고 승인 대본을 줄이거나 음성을 더 빠르게 만들지 않는다. 승인 음성과 타이밍을 유지하고 화면을 보완한다. 힌디어 1.3배속은 native 1.0 후 atempo 1.3 한 번이며, 이중 가속하지 않는다.
- 추가 이미지가 필요한 상태에서 이미지를 모두 검수받았다고 간주해 해당 영상 생성을 시작하지 않는다. 사용자가 지정한 이미지 검수 순서를 지킨다. 기존 승인까지 다시 요청하지 않는다.

### 생성 전 필수 확인
각 대사 구간마다 시작·끝·필요 초수, 화면의 시작/변화/결과, 기준 이미지, 생성할 클립 수와 길이, 사용할 예상 구간, 추가 이미지 필요 여부를 장면표에 기록한다. 10초 초과 구간은 분할 계획을 별도로 확인하고, 첫 60초와 결말도 점검한다. 분량 부족이나 미설계 구간이 있으면 준비 완료로 보고하지 않는다.
생성 후에는 요청한 길이가 아니라 실제 검수에 통과한 사용 가능 구간을 측정해 재대조한다. 생성 오류로 쓸 수 없는 부분과 겹치는 소스 구간은 확보 분량에서 제외한다. 정적 증거를 읽히는 경우에도 아래 최신 정지·중복 금지 기준을 따른다. 정지 화면 유지로 분량을 채우지 않는다.

## 생성 요청 순서·전체 움직임 검수 — 2026-10-19 사용자 지시
- Flow 이미지 요청은 한 건씩 실행한다. 앞선 요청의 출력 전체 완료(또는 명확한 실패) 확인 → 결과 검수 → 다음 요청 순서다. 생성 중인 상태에서 요청을 연속 제출하거나 일괄 대기열을 만들지 않는다. 실패도 기존 상태를 확인한 뒤 한 건만 재시도한다. 현재 Nano Banana 2.1/16:9/x2 설정을 임의 변경하지 않는다.
- 폐버스 본편은 전체 구간의 정지 이미지·동결·반복·정지 후 짧은 움직임을 검사한다. 첫 60초만 통과시키지 않는다. 원리 장면은 설명 대상의 작동을 확인하며 카메라 이동만으로 통과시키지 않는다. 현재는 이미지 보완 단계이고 최종 영상 검수는 미실행이다.


## 정지·중복 화면으로 시간 채우기 절대 금지 — 2026-10-19 최신 사용자 지시

- 본편에는 정지 이미지 전용 구간을 넣지 않는다. 마지막 프레임 동결, 정지 후 짧은 움직임, 중복 이미지 재배치, 같은 영상 구간 반복·루프·역재생·의미 없는 감속으로 시간을 채우는 행위를 금지한다. 이미지에 줌·팬만 적용한 것은 실제 영상 확보로 인정하지 않는다.
- 이미지 파일은 영상 생성의 기준 자료다. 이미지 수·장면 수·음성과의 시간 합계 일치, 모든 컷 8초 이하라는 조건만으로 영상 분량이나 움직임 검수를 통과시키지 않는다. 각 구간에 실제 검수된 움직이는 영상 또는 의미 있는 작동 애니메이션을 확보한다. 부족하면 새로운 구도·동작을 추가 제작하고 승인 대본·음성은 유지한다.
- 같은 대상을 다시 설명할 때도 새 구도·새 작동 단계·겹치지 않는 유효 소스 구간을 사용한다. 비연속 중복 이미지도 목록으로 추적하고 같은 화면을 재배치해 분량을 확보했다고 계산하지 않는다. 정적 문서·사진을 근거로 사용할 때도 본편 전체 화면을 정지 유지하는 예외로 삼지 않는다.
- 원리 장면은 설명 대상의 상태 변화가 보여야 한다. 카메라 이동·움직이는 자막·입자 효과만으로 통과시키지 않는다. 고장 난 장치를 임의로 작동시키거나 물리적 원리를 왜곡해서 움직임을 만들지 않는다.
- 이미지와 생성 영상 전부를 실제로 확인한다. 차체 비례·부품 연결·절개층·재료와 공간 관계·장면 간 일관성·워터마크·깨진 글자·뭉개짐·저해상도·어색한 합성을 검사한다. 잘못된 형상이나 설명과 맞지 않는 그림은 보류하고 수정한다. 파일 존재·해시·해상도 검사만으로 품질을 보증하지 않는다.
- 최종 렌더 전체 0초부터 끝까지 정지·동결·중복·루프를 탐지하고 실제 연속 재생 및 컷 경계를 확인한다. 컷별 소스/사용 구간/유효 움직임 길이/원리·품질 검사 결과를 남긴다. 첫 1분만 검사하거나 픽셀 차이만 확인하고 전체 정상이라고 보고하지 않는다.
- 전체 검수가 끝나기 전에는 “정지 장면 없음”, “중복 없음”, “이미지 품질 전부 정상”, “완성”이라고 확답하지 않는다. 미검수와 실패를 구분하고 수정 후 해당 구간과 연결부를 재검수한다. 이 규칙은 앞선 정지 도해·정적 증거·그림 확대 허용 문구보다 우선한다.



## 필수 분량 하한 — 이미지 기반 영상 총길이 ≥ 나레이션 길이 (2026-10-19)

- 영상 생성 전 반드시 `생성·검수된 서로 다른 이미지별 계획 영상 길이의 합계 ≥ 승인 나레이션 실측 길이`를 만족한다. 동일 길이 L초로 각 이미지에서 영상 1개를 만드는 경우 `이미지 수 N × L ≥ 음성 길이 T`, 필요한 최소 이미지 수는 `ceil(T/L)`이다. 길이가 다르면 각 이미지에 실제 배정한 길이를 합산한다.
- L은 현재 선택한 영상 도구·모델에서 지원하고 실제 생성할 길이여야 한다. 확인하지 않은 8초/10초를 가정하거나, 중복 이미지·장면표 분할·미생성 이미지·같은 소스 구간을 이중 계산하지 않는다. 길이 설정이 미확인인 경우 계산은 가정치로 표시하고 통과로 보고하지 않는다.
- 총량 조건과 함께 각 대사 구간에도 필요한 유효 영상 길이를 배정한다. 다른 내용의 여분 클립으로 특정 구간의 부족을 상쇄하지 않는다. 전환 겹침·앞뒤 트리밍으로 잃는 길이를 반영하고, 예상 손실에 필요한 여유분을 추가한다.
