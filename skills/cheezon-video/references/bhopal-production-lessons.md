# 보팔에서 검증한 제작 개선 — 다음 편 적용

적용 범위: Cheezon의 새 편 제작 및 요청받은 수정. 이미 승인된 대본·음성을 이 문서만으로 변경하거나 다음 편 생성·게시를 시작하지 않는다. 최신 사용자 지시가 우선한다.

## 음성부터 확정하고 화면 길이를 계산
- 한국어 내용 검수용 음성은 Voice Studio의 검증된 한국어 참조로 생성·조립해 전달한다. 한국어 ASR을 추가해 검수를 지연하지 않는다.
- 힌디어는 보팔에서 명료하다고 승인된 경로를 다음 편의 시작 설정으로 사용한다: Charon clone, 전체 ref_text, seed 7, native speed 1.0, raw, 64 steps 문단 단위 생성 후 FFmpeg `atempo=1.3`. 현재 실행 도구가 같은 설정을 지원하는지 확인한다. TTS speed 1.3과 atempo 1.3을 동시에 적용하지 않는다. 긴 문단을 여러 개로 나눠도 텍스트·순서는 고정한다.
- 정상인 참조 샘플과 설정이 있으면 재사용한다. 도구·참조·처리 방식이 바뀌거나 전체 음성 깨짐이 보고되면 짧은 샘플을 먼저 확인해 실패한 설정으로 전체를 반복 생성하지 않는다. 디코드 성공은 듣기 좋은 음질의 증명이 아니다.
- WAV의 샘플 수 / 샘플레이트로 최종 길이를 얻는다. 이전 음성 길이를 1.3으로 나눈 추정값을 새 시간표로 쓰지 않는다. 승인 후 대본과 음성 해시를 기록한다.
- 힌디어 ASR은 누락·연도·수치·반복과 정렬을 확인하는 보조 수단이다. TTS와 순차 실행하며 이상이 있는 소스 구간을 먼저 재검사한다. 전사문으로 승인 자막을 덮어쓰지 않는다. 문단 길이는 실측, 단어·문장 경계는 정렬 추정이라는 차이를 기록한다.
- 같은 승인 음성의 WAV는 편집, MP3는 재생 용도다. 깨짐 신고 시 원본·최종 영상에서 추출한 음성·재생 경로를 구별해 확인한다. 실제 청취, ASR, 파형 비교, 디코드 검사를 구분해 보고한다.

## 이미지 개수보다 필요한 화면 변화
- 승인된 실제 낭독 타임라인에서 각 설명에 필요한 장면·상태 변화를 배정한다. 이미지 26장을 확보했다고 7분 영상을 준비했다고 판단하지 않는다. 컷 수, 기준 이미지 수, 생성 영상 수는 서로 다르다.
- 문장 ID는 내용 대응용이다. 같은 장면의 문장 여러 개는 하나의 연속 장면으로 묶을 수 있다. 문장 수만큼 새로운 이미지·새 컷을 강제하지 않는다.
- 첫 60초와 결말은 별도 구간으로 검수한다. 도입의 사건·인물·장치 작동은 영상 또는 통제된 원리 애니메이션으로 보여준다. 긴 정지 이미지 나열을 배치한 뒤 후반만 영상화하지 않는다. 문서·사진·비교표는 증거로 사용할 수 있으나 본편을 정지 유지하는 예외가 아니다. SKILL.md의 최신 정지·중복 금지 기준을 따른다.
- 실사는 상황·피해·규모, 3D 단면/흐름/분해도는 내부 작동을 담당한다. 모든 핵심 원리를 화면으로 설명하는지 확인하며 실사 비율이나 생성 장수로 완성을 판단하지 않는다.

## AI 생성물의 구조와 상태 검수
- 입력 그림과 출력의 시작·중간·끝을 비교한다. 끊긴 배관이 연결됨, 정지 설비 재가동, 없던 모터 추가, 외부 누수, 물 분사 높이 변경은 원리를 바꾸는 오류다. 움직임이 있다는 이유로 채택하지 않는다.
- 검증된 구간만 크롭·마스크·합성할 수 있다. 움직여야 할 영역만 사용하고 유지해야 할 구조는 고정한다. 합성 경계와 주장에 맞는 작동을 다시 확인하고 출처·가공 이유를 기록한다.
- 인물·시설 장면의 안정된 카메라 이동은 허용한다. 유체 이동·힘·밸브 설명은 카메라 이동만으로 대체하지 않는다. 고장 난 설비를 움직이게 만드는 것도 해결이 아니다.
- 거절·실패 결과는 기존 작업 상태와 다운로드를 확인한 뒤 처리한다. 작업 ID, 프롬프트, 기준 이미지, 생성 상태, 채택/제외 이유를 남겨 중복 제출을 피한다.

## 문장 경계와 영상 경계를 분리
- 같은 장면을 5초 이미지로 유지한 뒤 2초만 영상으로 재생하고 전환하는 편집을 금지한다. 보팔 3:00 부근 문제는 10초 소스가 있었는데 문장별로 정지/영상을 나눠 배치한 것이었다.
- 같은 행동의 연속 설명은 연속 소스 프레임을 배정한다. `continuity_group`, 소스 경로, 소스 fps, `source_start_frame`, `source_end_frame`(끝 제외), 출력 프레임 범위를 기존 manifest에 대응 필드로 남긴다. 다음 구간은 앞 구간의 마지막 사용 프레임 다음에서 이어져야 한다.
- 출력 fps로 정규화한 소스를 기준으로 정확히 trim한다. 누적 시간 경계에서 프레임 번호를 계산해 각 컷 독립 반올림의 오차가 쌓이지 않게 한다. 연결 앞뒤 프레임과 실제 재생을 확인해 재시작·동작 점프·역행을 찾는다.
- 부족한 길이는 적합한 다른 구도·원리 애니메이션·승인 범위의 추가 생성으로 채운다. 마지막 프레임 동결, 무의미한 반복·역재생·슬로모션으로 채우지 않는다. 같은 소스의 별도 구간은 겹치지 않는 범위를 기록한다. 설명상 이전 장면을 비교 재사용하면 그 목적이 화면에서 드러나게 한다.
- 영상만 고칠 때는 승인 음성과 자막 내용·전체 타이밍을 유지한다. 시각 컷마다 음성을 잘라 다시 붙이지 않고 승인된 연속 오디오를 사용한다. 수정 컷과 의존하는 합성·캐시만 갱신한다.

## 검수 화면과 반복 신고
- 검수 화면의 현재 힌디어 문장과 한국어 대응문을 같은 구간에 표시한다. 승인 한국어 문단 전체는 별도 접힘 영역에 둔다. 같은 문단을 여러 컷에 표시한 것을 현재 대사가 반복되는 것처럼 보이게 하지 않는다.
- 반복 신고는 실제 음성 복제, 뜻이 겹치는 대본 문장, 같은 자막/문단 재표시, 반복 영상, 동시 재생을 구별한다. 해당 최종 파일 구간을 확인하고 원본·믹스·기존 ASR·자막을 대조한다. 대본 텍스트만 보고 음성에 문제가 없다고 단정하지 않는다.
- 원리 변화가 중요한 구간과 수정 구간은 약 0.25초 간격 프레임 표본·컷 경계·연속 재생을 확인한다. 픽셀 차이는 정지 탐지 보조이며 움직임의 정확성이나 시청 품질을 증명하지 않는다.
- 최종 파일은 전체 디코드, 실제 프레임 수/길이/해상도, 오디오 누락·클리핑, 자막 글꼴·잘림, 승인 입력 해시를 확인한다. 검수한 범위를 명시한다. 첫 1분과 끝부분에 정지컷이 없다는 결과를 전체 본편 정지컷 0개라고 쓰지 않는다.

## 납품·썸네일·업로드 자료
- 썸네일 생성 요청이 있으면 생성까지 수행한다. 프롬프트만 요청됐으면 그 범위에 맞춘다. 텍스트는 크게 굵게, 검은 외곽선. 글자색은 yellow/green/red/white만 사용하고 의미에 따라 일관되게 배정한다. 예: 노랑=핵심 질문/수치, 빨강=위험/실패, 초록=정상 기능/해결, 흰색=연결 문구. 네 색을 전부 사용할 의무는 없다. 본편 숫자 강조 규칙과 혼동하지 않는다.
- 제목·썸네일·첫 문장은 같은 문제를 약속한다. 승인 후 첫 문장을 임의로 다시 쓰지 않는다.
- 채널의 현재 공개 제목/설명 예시를 확인해 스타일을 맞춘다. 보팔 시점 관찰은 영어 질문형 제목, 사건·원리 소개 → 챕터 → 출처 → AI 영상/음성 안내 → 구독 문구였다. 관찰 당시 영상은 https://www.youtube.com/watch?v=bFGhZ7_VOPY 와 https://www.youtube.com/watch?v=ypbQlXFUtEo 이며, 다음 편에는 현재 형식을 다시 확인한다.
- 영어/힌디어 제목과 설명을 각각 작성한다. `upload_description_en.txt`, `upload_description_hi.txt`에 각 언어의 본문·챕터·출처·안내·구독 문구·해시태그를 완결되게 저장한다. 영문/힌디어 본문을 하나의 설명에 합치지 않는다. 한글 검토 번역은 공개 설명에 섞지 않는다.
- 키워드도 영어 8개/힌디어 8개를 각각 출력한다. 사용자 최신 선호는 영상과 관련된 범용 키워드다. 억지 유행어·무관한 키워드를 추가하지 않는다. 요청 없이 언어별 8개에 상세 태그를 더 붙이지 않는다.
- 최신 본편·썸네일·검수 페이지·업로드 메타데이터가 같은 결과물을 가리키는지 확인한다. 후처리 패키징 스크립트가 사용자가 확정한 제목/설명/태그를 옛 기본값으로 되돌리지 않게 한다.
- 게시 요청이 있으면 사용자가 지정한 기존 로그인 프로필을 사용한다. 접속 문제를 재로그인 요구나 격리 프로필로 우회하지 않는다. 예약 시간은 날짜·시간대와 함께 확인하고, 지난 시각을 완료로 처리하지 않는다. 문구 준비와 실제 업로드/예약 완료를 분리해 보고한다.
- 최신 결과의 정상 생성과 연결 확인 후 대체된 이전 결과·중복 다운로드·불필요한 중간 파일을 정리한다. 승인 대본·필수 소스·재현에 필요한 선택 기록은 유지한다. 삭제 대상 절대 경로를 확인하고 실제 확보 용량을 보고한다. 전체 프로젝트나 실행 중 파일을 무작정 삭제하지 않는다.
