# 장면 인계와 검수

연속 장면의 프레임 배정, 실제 음성 길이, 반복 신고, 최종 전달은 [보팔 제작 개선](bhopal-production-lessons.md)을 함께 적용한다.

## 최소 기록
대본 승인 전: `질문 ID | 부분 답 | 남은 실제 제약 | 회수 구간`.
영상 제작: `shot_id | 원문/힌디어 구간 ID | 질문 ID | 기능 | 시작 상태 | 동작 | 끝 상태 | 구조 고정점 | 기준 그림 | 카메라 | 근거 | 오버레이 | 사용 클립/소스 구간`.
필드는 기존 scenes/manifest 형식의 대응 필드로 기록해도 된다. 새 JSON 형식에 맞추려고 실행 스크립트를 임의 변경하지 않는다.

## 장치 예시 (서사 공식 아님)
압력 작동을 설명한다면 전체 배관 위치 → 해당 공간 단면 → 입구/출구 밸브 상태 → 압력 차에 따른 이동 → 다음 공간의 결과를 연결한다. 실제 장치의 순서와 방향은 기술 근거로 확인한다.
구조물은 하중의 출발점 → 전달 경로 → 지지 조건 변화 → 결과를 보여준다. 물은 수위·유입·유출·장애물의 관계를 보여준다.
관찰 불가능한 가정은 가정임을 표시한다. 도해에 사실처럼 새 부품·힘·사고를 추가하지 않는다.

## 프롬프트 인계
- 시작/끝 상태와 유지할 구조를 구체화한다. 부품과 화면의 색 이름을 매 컷 바꾸지 않는다.
- 카메라의 Movement/Speed/Framing/End와 물체의 동작을 따로 쓴다.
- 검증 가능한 글자·수치·라벨은 편집에서 넣는다. 생성물에 잘못 들어간 라벨은 설명 근거로 사용하지 않는다.
- 같은 장치의 연속 샷은 일치하는 방향 또는 명확한 전환으로 연결한다.

## 승인된 범위에서 문제 해결
정지 그림 확대·팬만으로 본편 영상 컷을 대체하지 않는다. 실제 움직이는 영상 또는 의미 있는 상태 변화 애니메이션을 확보한다. 유체 이동·밸브 순서·힘 전달의 필수 설명을 확대만으로 대체하지 않는다. 원리가 보이지 않으면 통제된 도해·다른 검증된 클립·허용된 재생성으로 해결한다.
이미 생성된 적합한 자산부터 확인한다. 수정이 새 비용·새 승인 범위를 요구할 때만 그 부분을 확인하고, 타임아웃 결과가 불명확하면 상태 확인 전 재제출하지 않는다.

## 완료 판정
기술: 실제 해상도/프레임/총 길이, 디코드 오류, 음성 누락·잘림·피크, 자막 글꼴·결합·화면 잘림.
의미: 각 핵심 설명이 가리키는 부품과 상태가 존재하는가; 힘·물·압력의 방향이 맞는가; 전후 연결에서 장치가 바뀌지 않는가; 최초 질문의 답이 실제 화면에 있는가.
편집: 의도 없는 소스 구간 반복·되감기·시간 역행을 timeline에서 확인한다. 설명을 위한 비교 반복은 비교임을 알아볼 수 있게 한다.
모티브의 과거 컷·말속도 통계는 관찰 자료이며 의미 검수를 대신하는 합격 기준이 아니다. 검증기 한계를 보고하고 미검사 항목을 합격으로 표시하지 않는다.

## 생성 전 분량 검증 — 필수
장면표 작성과 생성 제출 전에 [영상 스킬의 반드시 하지 말아야 할 것](../SKILL.md#반드시-하지-말아야-할-것--장면-분량-부족-재발-방지-2026-10-19)을 적용한다. 전체 시간 일치는 분량 충분성의 증거가 아니다. 각 대사 구간의 필요 초수와 화면 변화, 기준 이미지, 클립 수·길이·사용 구간, 추가 이미지 여부를 기록한다. 10초 초과 구간의 분할 계획을 확인하고 생성 후 검수 통과 구간의 실측 길이로 다시 대조한다.


## 정지·중복 화면으로 시간 채우기 절대 금지 — 2026-10-19 최신 사용자 지시
본편 전체에 SKILL.md의 최신 정지·중복 금지 기준을 적용한다. 반복 기준 이미지가 있으면 새로운 구도·동작·유효 소스 구간을 구체적으로 지정하고, 확보 전에는 제작 준비 완료로 표시하지 않는다.


## 필수 분량 하한 — 이미지 기반 영상 총길이 ≥ 나레이션 길이 (2026-10-19)

- 영상 생성 전 반드시 `생성·검수된 서로 다른 이미지별 계획 영상 길이의 합계 ≥ 승인 나레이션 실측 길이`를 만족한다. 동일 길이 L초로 각 이미지에서 영상 1개를 만드는 경우 `이미지 수 N × L ≥ 음성 길이 T`, 필요한 최소 이미지 수는 `ceil(T/L)`이다. 길이가 다르면 각 이미지에 실제 배정한 길이를 합산한다.
- L은 현재 선택한 영상 도구·모델에서 지원하고 실제 생성할 길이여야 한다. 확인하지 않은 8초/10초를 가정하거나, 중복 이미지·장면표 분할·미생성 이미지·같은 소스 구간을 이중 계산하지 않는다. 길이 설정이 미확인인 경우 계산은 가정치로 표시하고 통과로 보고하지 않는다.
- 총량 조건과 함께 각 대사 구간에도 필요한 유효 영상 길이를 배정한다. 다른 내용의 여분 클립으로 특정 구간의 부족을 상쇄하지 않는다. 전환 겹침·앞뒤 트리밍으로 잃는 길이를 반영하고, 예상 손실에 필요한 여유분을 추가한다.
- 생성 후에는 `오류·정지·중복·겹침·편집 손실을 제외한 실제 검수 통과 영상 길이 합계 ≥ 나레이션 길이`를 다시 확인한다. 요청한 길이나 파일 길이만으로 유효 분량을 인정하지 않는다. 모자라면 필요한 새 이미지·동작·클립을 보완한다. 정지·루프·감속으로 늘리거나 승인 음성을 줄여 맞추지 않는다.
- 이미지 수, 도구/모델/클립 길이, 생성 전 계획 총초수, 음성 실측 초수, 생성 후 유효 초수, 부족 초수와 구간, 검사 상태를 제작 기록에 남긴다. 이 하한은 필수 조건이며 품질·원리·전체 움직임 검수를 대신하지 않는다.
