# 편집 — 다음 정보가 보이게 연결한다

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

- 길이는 확정 힌디어 음성과 필요한 화면 호흡을 따른다. 6분에 맞추려고 대본·음성을 삭제·추가·과속하지 않는다.
- 원문 구간과 샷의 관계, 소스 클립과 사용 구간을 timeline에 남긴다. 핵심 설명에 맞는 실제 부품과 상태 변화를 배치한다.
- 대체로 2~3초 안팎의 다양한 컷을 염두에 두되, 단면의 움직임·숫자를 읽는 시간은 확보한다. 과거 컷 통계는 참고값이다.
- 도해·문서·비교는 고정 구도로 보여줘도 된다. 모든 샷의 줌인·무빙을 의무화하지 않는다.
- 기본은 명확한 컷. 연결에 필요한 경우 위치 일치·전후 비교·짧은 전환을 사용한다. 물체가 임의로 변형되는 모프를 원리 설명에 쓰지 않는다.
- 같은 동작의 의도 없는 루프·역재생·소스 시간 되감기·속도 급변으로 분량을 채우지 않는다. 의도적 비교·회수는 그 기능이 드러나게 한다.
- 원리 움직임이 필요한 컷을 정지 그림 확대만으로 대체하지 않는다. 검증된 대체 클립이나 통제된 그래픽으로 해결한다.
- 도입 분위기 공백을 늘리지 않는다. 의도적 강세·쉼·관찰 호흡은 허용한다. TTS의 기존 확정 낭독을 강제로 무쉼화하지 않는다.
- 원본은 보존하고 새 편집 버전으로 저장한다. 영상 전체 디코드와 설명 구간·접합부를 확인한다.
