# 음성과 소리

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

- 힌디어는 기존 Charon clone, raw, seed 7, speed 1.0과 완전한 ref_text를 사용한다. 성인 대상의 강한 어휘·강세·의도적 쉼을 적용하되 원문 의미·확실성을 보존한다. 차분한 교과서 말투를 의무화하지 않는다.
- 한국어 내용 검수는 기존 speaker 104 참조를 재사용한다. 동일 문장은 재사용하고 변경 구간만 생성·조립한다. 한국어 내용 검수 음성은 ASR/전사를 하지 않는다.
- TTS와 힌디어 ASR은 순차 실행한다. 힌디어는 문장 대응·숫자·고유명사·누락·잘림을 점검한다. 장문 ASR 누락은 해당 소스 구간을 확인하며 오인식을 원문 수정의 근거로 쓰지 않는다. seed 변경·재생성은 확인된 음성 문제에 한한다.
- 무료 Voice Studio 경로를 유지하며 유료 TTS로 자동 전환하지 않는다. 과거 영어/힌디어 참조가 한국어 설정에 남은 경우 기존 한국어 검증 설정을 우선한다.
- 쉼은 의미·강세·도해 관찰을 따른다. 한국어 모티브 말속도를 힌디어 속도 목표로 환산하지 않고, 확정 음성을 시간에 맞춰 과속하지 않는다.
- 전체 목표 -14 LUFS, 최고 peak -1.5 dBTP. 배경음은 승인된 파일을 쓰고 목소리 이해를 우선한다. 기존 Cheezon의 낮은 배경음(-42 LUFS 정규화 기록) 선호를 출발점으로 실제 믹스를 확인한다. 이전 19dB가 거슬린다는 피드백을 보존한다.
- 효과음은 변화·위험을 읽는 데 필요한 순간에만 사용한다. 개수·0.3초 상한을 기계적으로 적용하지 않으며 말끝을 덮지 않는다.
- 디코드·음량·자동 검사와 사람이 들었다는 주장을 구분한다. 한국어 검수 전달을 불필요한 전사로 지연하지 않는다.
