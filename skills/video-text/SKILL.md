# 자막과 화면 글자

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

- 공개 본편은 힌디어 한 줄 자막. Nirmala UI 등 데바나가리 지원 폰트와 ASS Spacing 0을 사용하고 결합 문자·폭·잘림을 렌더해 확인한다.
- 의미 단위로 타이밍과 줄 폭을 나눈다. 한국어 12자·Jalnan·영어 6단어 기준을 힌디어에 적용하지 않는다. 음성에 있는 의미·숫자·주체를 자막 편의로 생략하지 않는다.
- 한국어는 검수 문서·음성에 사용한다. 요청된 이중 자막 검수본은 힌디어 아래 한국어를 분리 배치하고 공개 본편과 파일을 구분한다.
- 생성 이미지 안에 정확한 글자·숫자를 맡기지 않는다. 오버레이는 근거값·단위를 확인하고 핵심 물체·자막과 겹치지 않게 한다. 숫자 강조는 노란 테두리다.
- 제목·썸네일·첫 장면은 같은 모순/문제를 약속하며 본편에서 회수한다. 플랫폼 입력 한도는 게시 시 확인하고, 과거 45자/60자 제한을 채널의 절대 길이로 쓰지 않는다.
- 썸네일은 요청에 따라 힌디어 문구와 구도 프롬프트를 제공한다. 큰 대상과 결과·모순 하나가 읽히게 한다. 기존 사용자의 채도 높은 노랑·빨강·초록 선호를 유지하며 흰 글자 기본값을 복원하지 않는다.
