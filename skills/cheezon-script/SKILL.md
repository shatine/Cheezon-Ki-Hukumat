# Cheezon 대본 — 보이는 모순에서 작동 조건까지

인도 시청자가 익숙한 대상에서 이상한 점을 발견하고, 처음에는 보이지 않았던 작동 조건을 이해하게 하는 대본을 만든다. 신비한 건축사전에서 가져오는 것은 **질문을 연결하는 기능과 화면으로 원리를 보여주는 방법**이다. 원문 문장·고유 비유·억양·장면을 번역하거나, Claude의 기존 점검표를 채우는 작업으로 바꾸지 않는다.

처음 사용하거나 구조를 다시 설계할 때 [상위 9편 분석](references/nine-video-analysis.md)을 읽는다. 실행·언어·기존 사용자 선호는 [채널 적용 규칙](references/channel-rules.md), 완성 전 판단은 [대본 검수](references/review.md)를 참고한다. 이 스킬은 대본을 담당한다. 장면 제작은 `cheezon-video`에 문장·질문·증거 장면을 인계하며, 생성 도구·크레딧·카메라 실행·렌더링은 해당 제작 요청의 범위에서 다룬다.

## 0. 문제를 먼저 만들고 끝까지 회수한다

새 소재 선정·대본·구조 검토에는 [문제와 질문 연결](references/curiosity.md)을 먼저 적용한다. 시설 소개보다 대상의 설명되지 않는 모순·불편·위험을 먼저 세우고, 제목·썸네일 약속·첫 장면·결말이 같은 질문을 가리키게 한다. 각 부분 답은 다음 설명이 필요한 실제 제약으로 이어진다. 고정 반전 횟수나 답을 미루는 문구로 대신하지 않는다.
소재 후보는 같은 소재의 실제 100만 조회 영상 증거를 먼저 확인한다. 시청 형식·언어권을 구분하고 기술 사실은 별도 검증한다. 장면 인계에는 질문 ID와 보일 상태 변화를 연결한다. 이 구조 설계는 한국어 검수 전에 완료한다.

## 1. 소재의 질문부터 확정한다

사용자가 고른 소재로 시작한다. 아직 선택하지 않았다면 기존 후보 중 근거 있는 선택지를 좁히되, 선택 요청을 곧바로 제작 지시로 해석하지 않는다.

첫 문장보다 먼저 다음 네 가지를 적는다.

- 시청자가 직접 본 장면: 구체 장소·물건·행동 하나.
- 보이는 모순: 예상한 결과와 실제 결과가 어떻게 다른가.
- 걸린 것: 위험·돈·시간·권리·생활 불편 중 실제 근거가 있는 결과.
- 중심 질문: 일반 시민이 그 장면을 보며 품을 질문. 운영자만 궁금한 전문 문제는 답을 설명하는 과정에서 등장시킨다.

중심 질문이 공학·운영·제도 중 무엇으로 풀리는지 구분한다. 낱말의 유래만 있고 검증 가능한 원인이나 결과가 없으면 장편으로 억지 확장하지 않는다. 소재 하나에 확인되지 않은 범죄·사고·음모를 덧붙여 긴장을 만들지 않는다.

한 편은 중심 질문 하나를 푼다. 그것을 설명하는 데 필요하면 관련 장치나 두 사례를 함께 다룰 수 있다. 물건이 두 개라는 이유로 금지하거나, 반대로 관계없는 사례들을 묶어 카탈로그로 만들지 않는다.

## 2. 근거와 작동 경로를 먼저 만든다

주장 ID별로 `주장 | 지역·기준일 | 단위·정의 | 원문 근거 | 확인/충돌/미확인 | 들어갈 문단`을 기록한다. 인도 현장의 수치·법규·운영 방식은 별도로 검증한다. 모티브 영상은 서사의 근거이며 그 안의 기술·역사 주장을 새 대본의 사실 근거로 재사용하지 않는다.

핵심 원리를 `어디서 → 무엇이 → 어느 경로로 → 무엇 때문에 변하고 → 어디로 가는가`로 그린다. 물질이면 흐름, 구조물이면 하중·열·힘, 제도면 정보·돈·허가의 경로다. 부품 이름보다 움직임과 조건을 먼저 설명한다.

숫자는 원인을 판단하게 할 때 넣는다. 규격·제약·측정 결과·지속 비용을 보여주지 않는 숫자 나열은 줄인다. 비교 비유는 직접 계산하고, 설계 용량과 실제 처리량·한 번의 이용 인원과 하루 판매량을 구별한다. 과거 사건의 재판 상태는 당시 날짜와 현재 상태를 구별한다.

## 3. 답이 다음 질문을 만들게 구성한다

각 문단에 아래 연결을 만든다.

`지금 아는 것 → 새로 드러난 제약 → 그 제약에서 나온 질문 → 원리/사례로 답 → 눈으로 확인할 변화 → 남은 문제`

이 구조를 모든 문단의 표면 문구로 반복하지 않는다. 내부 기획에서만 사용한다. 후속 질문을 제거해도 앞뒤가 그대로 이어진다면 억지 질문인지 검토한다.

소재에 맞는 전개를 고르거나 결합한다.

- **운영 균형**: 움직이거나 새는 것을 없앨 수 없을 때, 어느 높이·경로·양으로 조절하는가. 해결 뒤의 계측·운영을 보여준다.
- **역할·범위 전환**: 물건 자체의 성능만으로 안 풀릴 때, 땅·배관·설치 조건·용도까지 질문을 넓힌다.
- **물질의 여정**: 한 물질을 따라가며 변환→부산물→분리→재사용을 설명한다. 나중에 배경 공정을 설명하더라도 실제 공정 순서를 틀리게 보여주지 않는다.
- **복원·검증**: 겉모습과 원래 조건이 어긋날 때, 그 어긋남을 드러내는 증거→복구→복구가 만든 새 문제를 쫓는다.

시청자가 떠올릴 대안은 실제로 그럴듯하고 근거로 한계를 설명할 수 있을 때만 다룬다. 일부 조건에서 가능한 해법을 전면 불가능이라고 쓰지 않는다. 두 번의 격파나 한 번의 반전을 채우려고 가짜 대안을 만들지 않는다.

해법 공개 시점은 **그 해법을 납득할 전제가 갖춰진 때**다. 정답을 초반에 주고 과정을 증명해도 된다. 40~50% 지점·반전 횟수·특정 연결 문장을 의무화하지 않는다. 해결 다음에는 실제로 남은 위험·비용·유지관리·측정 결과 중 해당하는 것을 붙인다. 뒷부분이 길어야 한다는 이유로 별개의 사건을 추가하지 않는다.

## 4. 장면이 떠오르는 한국어 검토본을 쓴다

첫 순간부터 구체 대상과 이상한 결과를 보여준다. 장소 소개, 사고의 결과, 현재 상태 중 가장 명확한 입구를 고른다. 꼭 특정 단어로 시작할 필요는 없다. 도입을 읽은 시청자가 대상·모순·궁금한 것을 설명할 수 있게 한다.

짧은 평서문을 기본으로 하고 한 문장에 원인과 결과를 과하게 쌓지 않는다. 전문어는 실제 행동을 보여준 뒤 필요한 만큼 풀어 쓴다. 비유 하나가 다른 성질까지 설명하는 척하지 않는다. 의인화는 실제 경로나 힘의 방향이 설명된 뒤 맛을 더할 때만 쓴다.

핵심 문단마다 `증명할 것 | 화면의 대상·변화 | 근거 ID`를 연결한다. 그 문장에 맞는 화면이 떠오르지 않으면 추상 설명을 줄이거나 경로를 다시 설명한다. 정밀 형상·숫자는 검증된 도해와 편집 글자로 표현하고 AI 재현을 실제 증거처럼 말하지 않는다.

마무리는 첫 질문에 답하고, 작동을 동사로 압축하고, 처음 본 장면이 어떻게 다르게 보이는지 보여준다. 새 주장이나 시청자 훈계를 붙이지 않는다. 기존 채널의 마무리 선호는 유지하되 모티브 채널의 문장 복제를 필수로 삼지 않는다.

## 5. 힌디어로 같은 뜻을 제작한다

한국어 검토본에 구간 ID를 붙인다. 사용자가 검수를 완료한 파일과 버전을 확정 원본으로 고정한다. 승인 후 내용을 추가·삭제·요약·확장·재배열하거나 한국어 원문을 수정하지 않는다. 일부 구간 승인과 전체 승인을 구별한다. 힌디어는 확정본과 문장별로 대응시켜 모든 내용과 순서, 주장, 숫자, 불확실성, 책임의 주체를 보존한다. 성인 대상의 강한 어휘와 강세는 의미를 바꾸지 않는 범위에서 적용한다.

숫자·연도는 정확한 값과 힌디어 낭독형을 대응시킨다. 각 구간을 `한국어 의미 | 힌디어 | 달라진 표현/근거`로 대조한다. '공개되지 않음'을 '의도적으로 숨김'으로, 상관을 원인으로, 기소를 유죄로 강하게 바꾸지 않는다. 이름·방향·단위 생략이 의미를 흐리지 않는지도 확인한다.

6분 상한은 폐기됐다. 영상 길이는 확정본의 실제 힌디어 낭독과 필요한 화면 호흡을 따른다. 시간에 맞춰 대본을 줄이거나 늘리지 않는다. 번역·음성·자막·이미지 프롬프트·영상·편집·렌더링 모두 검수 완료본 그대로 제작한다. 확정 이후 대본 수정 단계는 없으며, 에이전트가 필요성을 판단해 수정안을 만들거나 재검수를 요청하는 예외 절차도 두지 않는다. 번역·발음·자막은 확정 원문에 정확히 맞춘다. 자세한 승인 범위는 [채널 적용 규칙](references/channel-rules.md)을 따른다.

## 6. 요청 단계에 맞게 전달한다

대본 요청의 기본 결과는 한국어 검토본, 중심 질문과 문단 연결, 핵심 근거표, 중요한 수정·미확인점이다. 힌디어 제작까지 요청받았거나 이미 승인된 단계라면 힌디어 낭독문과 의미 대조도 포함한다. 대본만 요청했는데 영상·음성·썸네일을 생성하지 않는다.

[대본 검수](references/review.md)를 적용해 고친 뒤 최종본을 낸다. 모티브 분석의 관찰, 그로부터 도출한 설계 판단, 현재 소재의 사실 근거를 섞지 않는다. 조회수만으로 시청지속시간·CTR·성공 원인을 입증했다고 말하지 않는다.
