# 대본 검수 — 문구 개수 대신 이해할 수 있는가

## 현재 기획 확인

- 같은 소재의 100만 이상 영상 링크·실제 조회수·확인일·형식·언어권이 있는가? 다른 소재·채널 평균으로 대체하지 않았는가?
- 제목·썸네일 약속·첫 장면·결말이 같은 중심 질문인가? 시설 연혁을 먼저 설명하느라 질문이 늦어지지 않는가?
- 질문마다 부분 답이 생기고, 그 답이 드러낸 실제 제약 때문에 다음 설명을 듣게 되는가? 빈 예고·억지 반전·카탈로그 전개가 아닌가?
- 핵심 원리마다 증거·상태 변화 장면이 연결됐는가? 이 계획 변경이 승인된 원문을 침범하지 않는가?

## 보팔에서 추가한 검수 전 확인
- 제목·썸네일의 핵심 의문이 첫 문장에서도 같은 의미로 전달되는가? 답이나 장치 사양을 먼저 길게 설명해 질문을 약화시키지 않는가?
- 이웃 문장이 같은 사실을 말만 바꿔 되풀이하지 않는가? 예를 들어 “약품과 접촉시켜 반응한다” 다음에 “약품과 제대로 만나야 한다”만 반복하면 작동 조건·실제 제약이 새로 드러나는지 확인한다. 검수 전 불필요한 의미 중복을 정리하되, 이미 승인된 원문에는 소급 적용하지 않는다.
- 문장 ID는 의미 대응용이다. 한 장면이 여러 문장을 연속으로 설명할 수 있으므로 문장마다 새 이미지·새 컷을 요구하지 않는다.

## 완성 전 질문

1. 도입만 읽고 일반 시민이 대상·모순·궁금한 것을 말할 수 있는가? 강한 숫자·결과가 본론 질문과 연결되는가?
2. 물질·힘·정보의 경로를 그릴 수 있는가? 부품 이름을 알지만 작동을 못 그리면 설명이 빠졌다.
3. 문단마다 답이 더 정확해지는가? 순서를 바꿔도 상관없으면 카탈로그인지 본다.
4. 대안의 한계를 근거로 설명하는가? 비싼 것·조건부 가능한 것을 전면 불가능이라고 과장하지 않는가?
5. 조건이나 관찰이 바뀌어 결론이 달라지는가? 정해진 시점을 채우려고 넣은 반전은 지운다.
6. 핵심 수치·이름·연도·법적 상태에 근거가 있는가? 추정·조사 중·실측·용량을 구별하는가?
7. 문장에 대응하는 변화·단면·비교가 있는가? AI 재현을 실제 사진·설계 증거로 착각하게 하지 않는가?
8. 해법의 실제 대가·관리·남은 조건이 있는가? 없으면 억지 후속 사건 없이 마무리한다.
9. 끝에서 도입의 질문을 닫는가? 처음 대상을 다르게 보는 근거가 본론에 있는가? 결론에서 새 주장·훈계를 추가하지 않는가?
10. 힌디어가 같은 숫자·주체·의도·확실성을 말하는가? 고유명사·방향·단위가 생략·변경되지 않았는가?
11. 한국어 검수 완료본의 파일과 버전을 기준으로 모든 문장·순서가 보존됐는가? 시간이나 제작 편의 때문에 추가·삭제·요약·확장·재배열한 내용이 없는가? 6분 상한을 다시 적용하지 않았는가?

한국어 검수 전에는 미달을 문구 개수로 보완하지 말고 근거와 설명 순서를 고친다. 검수 완료 뒤에는 원본을 고정하고 그대로 제작한다. 확정 이후 대본 수정 단계나 에이전트 판단에 따른 수정안·재검수 예외 절차를 두지 않는다. 이후 확인은 번역·음성·자막·영상이 확정본을 충실히 따르는지에 한정한다. 일괄 '모두 통과'를 근거 없이 주장하지 않는다.

## 설치 전 자체 행동 검토

문서의 판단 기준을 아래 상황에 적용해 검토했다. 외부 독립 평가·업로드 성과·새 편 제작 실험은 아니다.

| 상황 | 기대 행동 | 반영한 기준 |
|---|---|---|
| 20초 안에 답을 준 처리시설 | 답을 늦추지 않고 과정·부산물을 설명 | 시점 고정 삭제, 물질 여정 허용 |
| 표시의 유래만 있고 위험 미확인 | 사고·음모를 만들지 않고 근거 범위를 제한 | 질문·근거 우선 |
| 역장만 궁금한 기술 문제로 시작 | 승객이 본 표시의 이상함으로 질문 변경 | 전문 문제는 답의 과정에 |
| 다리와 댐으로 같은 책임 문제 설명 | 인과가 연결되면 두 사례 허용 | 물건 하나라는 형식적 금지 삭제 |
| 물을 더 공급하는 해법이 조건부 가능 | 비용·양·설치 조건을 구별 | 모든 대안을 불가능으로 쓰지 않음 |
| 비공개가 숨김으로 번역됨 | 의도 강화를 찾아 원래 확실성으로 수정 | 구간 의미 대조 |
| 모티브 영상을 기술 근거로 인용 | 공식 자료·독립 근거로 다시 확인 | 서사·사실 근거 분리 |
| 과거 기소·구금이 현재처럼 낭독됨 | 당시 날짜를 붙이거나 최신 상태 확인 | 시점 구별 |

새 편에서 실제 이해·설명 오류가 드러나면 해당 판단을 좁게 수정한다. 한 실패를 모든 소재의 의무 문구·반전 횟수·분량 비율로 만들지 않는다. 사용자가 고친 대본의 구체 전후 차이를 개선 근거로 삼는다.
