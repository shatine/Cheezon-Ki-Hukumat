# Cheezon에 적용할 범위

## 언어와 검토

사용자와의 대화·대본 검토는 한국어다. 본편 내레이션·자막은 힌디어, 공개 업로드 글은 힌디어·영어다. 한국어 검토 문서·음성을 공개 본편에 넣지 않는다. 제작 프롬프트는 기존 흐름처럼 영어로 작성할 수 있다.

한국어 전문으로 검토할 수 있게 만들고 근거와 중요한 구조를 함께 준다. 사용자가 맡긴 단계에 따라 힌디어 제작을 이어간다. 기존 편의 승인 범위를 다시 물어 지연하지 않고, 검토만 요청된 편을 유료 생성까지 확장하지 않는다.

## 검수 완료본 고정 — 모든 제작 단계에 적용

사용자가 한국어 검수를 완료하면 승인한 파일과 버전을 확정 원본으로 보존한다. 일부 구간 검수와 전체 대본 검수를 구별한다. 지침 설정이나 음성 생성 요청만으로 대본 전체가 승인됐다고 판단하지 않는다.

검수 완료 뒤에는 내용·정보·예시·문장 순서·숫자·인과·확실성을 임의로 바꾸지 않는다. 힌디어는 문장별로 같은 내용을 빠짐없이 대응시킨다. 자연스러운 문법·어순과 승인된 강한 성인 대상 어휘·강세는 적용하되 뜻을 새로 만들거나 문단을 재창작하지 않는다.

6분을 넘어도 된다. 과거의 360초 영상 상한과 330초 내레이션 예산은 현재 규칙에서 폐기됐다. 확정본을 시간에 맞추려고 줄이거나 늘리지 않는다. 실제 낭독 길이에 맞춰 화면과 편집을 구성한다.

확정 이후 대본 수정 단계는 없다. 검수 완료본 그대로 번역·녹음·제작한다. 에이전트가 사실 수정, 문장 개선, TTS 발음, 장면 생성 편의 등을 이유로 수정안을 만들거나 재검수를 요청하는 예외 절차도 두지 않는다. 번역·발음·자막은 확정 원문에 정확히 맞춘다.

한국어 내용 검수용 음성은 전사 검사를 하지 않는다. 기존과 같은 문장은 기존 음성을 재사용하고, 변경된 부분만 생성·조립해 바로 전달한다. 힌디어 제작 검증과 한국어 초안 청취를 혼동하지 않는다.

힌디어에서는 인도 사람이 익숙한 표기·기관·단위·상황을 쓴다. 한국 법규·서울 시설의 성능을 인도 현장에 그대로 붙이지 않는다. 고유명사·유량·하중·lakh/crore 변환·설계/실측을 대조한다.

## 설명을 화면으로 옮기는 접점

문단의 화면은 분위기보다 주장에 필요한 관찰을 정한다. 장소 전체에서 부품 위치를 잡고 단면·경로·움직임으로 원리를 보인 뒤 전체 결과로 돌아간다. 단계 사이 방향·위치·색 의미를 유지한다.

본편은 밝은 인도 실사풍과 색이 분명한 3D 도해다. 정밀 숫자·라벨은 편집에서 넣는다. 가운데 70%의 핵심 대상과 아래 자막 영역을 고려한다. 숫자 그래픽은 노란 테두리이며 자홍 테두리를 쓰지 않는다는 선호를 유지한다.

영상 프롬프트까지 맡았을 때 기존 카메라 스킬의 `장면 + 카메라 태그 + Movement / Speed / Framing / End` 형식을 사용한다. 클립당 무빙 하나를 정하고 사람에게 다가가 얼굴이 커지는 동작을 피한다. 인도 성인·실존 인물 재현 금지·어린이와 큰 정면 얼굴 회피의 기존 규칙을 따른다. 이 대본 스킬은 별도 카메라 스킬을 새로 만들거나 도구를 실행하지 않는다.

약 2~3초의 전개를 염두에 두되 원리가 이해되도록 필요한 관찰 시간을 준다. 정적 자료·정밀 도해까지 무조건 흔들거나 확대하지 않는다. 작동을 빠뜨리고 컷 숫자만 채우지 않는다.

## 기존 실패를 대본 단계에서 예방

- 압력솥·역장 문제: 일반 시민의 장면과 실제 결과에서 질문을 시작한다. 내부 운영 용어를 핵심 질문으로 먼저 내지 않는다.
- 작은 모르비 다리: 화면 계획에 실제 규모와 구별되는 핵심 형상을 근거와 함께 기록한다. AI 이미지가 맞다는 이유로 수치를 확정하지 않는다.
- 비공개→숨김 번역: 원문보다 의도·책임을 강하게 만들지 않는다.
- 숫자 오인식·한국어 잡음: 낭독형 숫자 대응표를 준비한다. 기존 음성 로그의 1979/1989 허용 예외를 사실 검증의 통과로 쓰지 않는다.
- 어두운 술라브: 긴장감을 저노출·세피아·회색으로 표현해야 한다고 가정하지 않는다.

## 단계와 범위

다섯 완성본을 다시 만들 권한은 이 스킬 제작에 포함되지 않는다. 다음 소재는 사용자가 선택한 뒤 진행한다.

썸네일은 최신 요청 범위를 따른다. 프롬프트 요청이면 프롬프트를, 생성 요청이면 생성물을 제공한다. 대본 요청만으로 생성하지 않는다. 글자색·외곽선과 음성·편집·납품의 최신 실행 기준은 cheezon-video의 `references/bhopal-production-lessons.md`를 따른다.

Voice Studio·Flow·Muse·Grok·캡컷의 기존 제작 흐름을 변경하지 않는다. 음성·영상 생성은 실제 제작 요청에서 처리한다. 로컬 세션 한도 때문에 클라우드에서 작성한 모르비 v3의 편집 스크립트는 영상 생성 방식과 무관하다.
