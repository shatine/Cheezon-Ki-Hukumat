# 최종 검수

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

1. 확정 대본·힌디어·자막의 문장·숫자·순서를 대조한다. 한국어 내용 검수 음성에는 ASR을 실행하지 않는다. 힌디어 제작 검사에서는 장문 ASR의 누락을 소스 구간으로 확인한다.
2. 전체 파일 디코드, 길이·프레임·실제 해상도, 음성 누락·잘림·소리 튐·피크, 자막 결합 문자·잘림·오버레이 가림을 검사한다.
3. 주요 원리의 시작·변화·끝 상태를 관찰한다. 힘·물·압력 방향, 구조·색·위치의 연속성과 질문의 회수를 확인한다. 형식 검사만으로 설명이 맞다고 선언하지 않는다.
4. timeline의 소스 구간 반복·시간 역행·급격한 속도 변화와 실제 접합부를 확인한다. 의도된 비교와 분량 채우기 반복을 구별한다.
5. 기존 check_output.py와 targets.json은 호환되는 결과에 보조 진단으로 사용한다. 모티브의 첫 문구·샷 수·말속도·쉼·단일 자막 비율은 현재 일괄 합격선이 아니다. 이중 자막 검수본은 해당 요청의 별도 기준으로 확인한다.
6. 알려진 Windows 컷 감지 오류와 힌디어 단어 수 오류는 별도 도구/실측으로 보완한다. 검사하지 못한 항목과 자동 확인·실제 관찰·사람 청취를 구분해 보고한다.
7. 원본은 보존한다. 워터마크·로고 유무와 적합한 납품 경로를 확인하며 과거 고정 좌표 마스크를 현재 결과에 무조건 적용하지 않는다. 승인된 처리 범위와 현재 도구 조건을 따른다.

과거 기준 영상과 측정값은 [관찰 통계](refs/historical-observations.md), 기존 측정 JSON은 refs/에 있다. 기존 검사 스크립트·수치 파일은 이 지침 수정으로 자동 변경하지 않는다.
