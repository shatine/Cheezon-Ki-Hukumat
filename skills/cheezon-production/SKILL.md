# Cheezon 제작 (7편 기준, 2026-10-24)

이전 편들의 스킬·교훈은 모두 삭제했다. 이 폴더만 따른다. 최신 사용자 지시가 이 문서보다 우선한다.

## 먼저 읽기 (빠짐없이)
1. [references/process.md](references/process.md): 전체 순서, 단계별 규칙, 검수 표, 7편 실수와 대책
2. [references/script-and-voice.md](references/script-and-voice.md): 대본, 힌디어, 음성, 자막
3. [references/prompts.md](references/prompts.md): 이미지·영상 프롬프트 틀과 카메라 규칙

## 공정 한눈에
1. **도입부 첫 문장(중심 질문)을 정한다.** 썸네일 문구도 이 문장으로 확정하고, 제목도 같은 질문을 가리킨다.
2. **대본:** 한국어 대본과 근거표를 쓰고 → 사용자 검수 → 확정 고정 → 힌디어 문장 대응 → TTS → 실측 시간표.
3. **장면 계획:** 문장 단위로 `tools/plan_template.py`에 채우고, 자동 점검 오류가 0이어야 한다.
   - 3D 원리 설명은 반드시 영상이다.
   - 나머지 장면은 10~20%만 영상이다(카메라 무빙·동작). 그 외는 이미지에 효과를 넣는다.
   - 이미지는 2~4초마다 바꾼다.
   - 영상은 쓸 수 있는 구간을 최대한 쓴다.
   - 도입 30초는 긴 자연스러운 영상 3~5개로 만든다.
   - 감속, 정지, 반복은 금지한다.
4. **이미지:** Flow에서 한 장씩 만든다. 기준 그림을 첨부하고 일관성을 엄격히 검수한다. 기록은 `picks_*.md`에 남긴다.
5. **영상:** Muse에서 한 개씩 만든다. 고정 카메라가 기본이다. 프레임과 밝기를 측정해 쓸 구간을 기록한다.
6. **편집:** `tools/edit_template.py`로 하고, 0초부터 끝까지 검수한다.
7. **업로드 자료:** 영어·힌디어 제목과 설명을 따로 쓴다. 키워드는 8+8. 썸네일 문구는 도입부 문장(힌디어)으로 한다.

## 채널 고정값
- **시청자·언어:** 인도 성인.
  - 본편 낭독·자막은 힌디어, 사용자와의 대화·검수는 한국어, 업로드 문구는 영어·힌디어 각각.
- **화면:** 밝고 선명한 인도 실사풍 + 밝은 3D 도해(색 약속: 열 = 빨강·주황, 냉기 = 하늘색, 깨끗한 물 = 파랑, 오수 = 갈색·회색, 전기 = 노란 심선, 물기 = 흰 물방울).
  - 사람은 인도 성인만, 얼굴은 작게.
  - 생성 그림 안에 글자·로고·번호판이 있으면 안 된다.
- **납품:** 1920×1080 / 30fps.
- **도구:**
  - 이미지: Flow(프로젝트 baa9c0e8-3cbd-454c-a5e4-afa8d4f469cd, Nano Banana 2.1, 16:9, 무료). 9222 크롬은 쓰지 않는다.
  - 영상: Muse(크롬 9227).
  - 한 개씩 생성한다(봇 탐지 방지).
- **역할:** 클라우드 세션은 대본·계획·프롬프트·검수·업로드 문구, PC 세션은 생성과 렌더.
  - 주고받기는 GitHub https://github.com/shatine/Cheezon-Ki-Hukumat 의 `main`으로 한다.
  - 미디어는 클라우드가 받은 뒤 깃에서 지운다.
- **정리:** 새 결과가 확정되면 대체된 이전 판은 지운다.

## 도구 (tools/)
| 파일 | 용도 |
|---|---|
| `plan_template.py` | 문장 단위 컷 계획과 자동 점검(7편 plan_v9). 새 편은 SEG·VID·IMG만 새로 채운다 |
| `edit_template.py` | 계획대로 렌더하고 자막을 넣는다. 옵션: 좌우 반전, 밝기 보정, 흐림, 아지랑이 (7편 edit_v9) |
| `tts_template.py` | 힌디어 Voice Studio TTS와 실측 시간표(7편 tts_v5). 같은 폴더의 다음 파일을 쓴다 |
| `tts_vs.py`, `junk_check.py`, `asr_check.py`, `fw_local.py` | Voice Studio TTS 생성과 잡음·ASR 검사 |
| `voice_ref_male_charonclone.wav`, `ref_text.txt` | 목소리 기준 파일과 기준 문장(1편 tts_meta.json에서 옮김) |
| `image_prompts_example.py` | 이미지 프롬프트 작성 예시(7편 v9, 31장) |

7편 실제 자료 전체는 저장소 `episodes/ep07_bus/`에 있다(대본, 계획, 검수 기록, 업로드 문구).
