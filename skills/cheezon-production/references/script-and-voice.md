# 대본·힌디어·음성·자막 (7편 기준)

## 한국어 대본
- **구조:** 질문 → 기(첫 번째 문제) → 승(두 번째·세 번째 문제) → 전(실제 사례) → 결(처음 질문으로 돌아가 답).
  - 7편: `episodes/ep07_bus/script/script_ko_v3.md`.
- **대본 쓰기 전에 설계를 확정한다:** 본 장면, 보이는 모순, 중심 질문, 반전 한 줄, 놀라움, 마지막 깨달음, 썸네일과 첫 문장.
- **한 문제의 답이 다음 문제로 이어지게 한다.** 7편 예: 열을 고치면 → 물·오수 → 그 호스의 반대편은 땅 → 법.
  - 해결책을 나열하거나 질문과 무관한 변명은 뺀다. 7편 "뺀 것과 이유" 표를 참고한다.
- **문장:**
  - 사용자가 고쳐 쓴 문장은 그대로 쓴다.
  - 어색하거나 추상적인 문장, 사실과 다른 비유는 쓰지 않는다. 7편 예: 열이 "빠져나간다"는 식의 방향 오류.
- **근거표:** ID | 주장 | 출처 URL | 상태(확인/계산/일반 원리/미확인).
  - 미확인 주장은 사용자 결정을 받는다.
  - 판결·법 조항은 원문 그대로만 인용하고, 적용 범위를 넓히지 않는다.
- **숫자 (사용자 2026-10-24):** 출처마다 숫자가 다르면 **가장 높은 숫자**를 쓴다(숫자가 클수록 후킹). 근거표에는 다른 값과 "높은 숫자 채택"을 적는다. 정부·회사 주장은 문장 안에서 출처를 밝힌다("정부는 …라고 밝혔다").
- **실존 인물:** 사례는 기사로 확인한 사실만 쓴다. 화면에서는 재현하지 않는다(차·장소·뒷모습·손만).
- **확정:** 사용자 검수가 끝나면 파일을 고정한다. 이후 내용·순서·숫자를 바꾸지 않는다.

## 힌디어
- 문장 단위로 대응해 번역한다. 줄마다 `id \t 힌디어 \t 한국어 직역` (7편 `script/lines_hi_ko.tsv`, 88줄).
- 숫자는 낭독하기 쉽게 글자로 풀어 쓴다(예: दो हज़ार इक्कीस). 영어 고유명사는 데바나가리로 쓴다.
- 마지막 줄은 구독 문구: "ऐसी और कहानियाँ पाने के लिए, सब्सक्राइब और हाइप ज़ोर से दबाइए!"

## 음성 (Voice Studio, 무료)
- **설정:** charonclone, seed 7 고정, 속도 1.0, 문장 단위 생성, 문장 -16 LUFS.
- **불량 처리:** junk_check로 엄격하게 검사한다. 불합격이면 같은 seed로 쉼표를 바꿔 다시 만들고, 그래도 안 되면 쉼표에서 나눈다.
- **쉼:** 같은 문단 안 문장 사이 0.35초, 문단 사이 0.8초.
- **도구:** `tools/tts_template.py`를 새 편 `review_edit\`에 복사해 쓴다.
  - 결과: `narr\{id}.wav`, `narration_hi.wav`, `narr_timing.json`(줄별 시작·끝 실측).
- **장면 계획 기준:** 반드시 `narr_timing.json` 실측으로 한다. 음성을 빠르게 하거나 잘라서 화면에 맞추지 않는다.
- 사용자가 들어서 확인한 것과 자동 검사 결과를 구분해서 보고한다.
