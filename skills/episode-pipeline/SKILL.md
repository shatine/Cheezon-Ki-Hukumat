# 에피소드 제작

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

## 현재 흐름
1. 같은 소재 100만 조회 사례와 별도 사실 근거를 기록한다. 기존 KEEP 후보를 사용자 선택 없이 제작하지 않는다.
2. cheezon-script로 한국어 대본, 질문 연결, 근거, 증명 장면을 준비한다. 검수 완료 파일/버전을 고정한다. 반전 문구·비율 점검표는 쓰지 않는다.
3. 같은 내용을 힌디어로 문장 대응한다. Voice Studio 설정과 한국어/힌디어 검사 차이는 video-sound를 따른다. 실제 낭독 길이를 기준으로 장면을 계획한다.
4. 원문 구간·질문·전후 상태·핵심 구조·카메라·오버레이를 연결한다. 기존 자산부터 확인한다.
5. 사용자가 지정한 이미지 도구와 검수 범위를 따른다. 이미지 검수 후 영상 지시가 있으면 그 단계를 거친다. 최근 직접 이미지 생성/Muse 경로를 과거 Grok/Veo 기본값으로 덮지 않는다.
6. 확인된 계정·도구 상태에서 승인된 범위의 영상을 생성한다. 현재 비용·한도 확인, 결과 추적, 타임아웃 후 중복 제출 방지. 기존 승인에 포함된 수정은 불필요하게 다시 묻지 않는다.
7. 확정 음성에 맞춰 컷·설명 도해·자막·숫자·음악을 편집하고 video-verify로 기술과 의미를 확인한다.
8. 승인된 요청 범위의 1080p 본편·자막·캡컷·업로드 자료·썸네일 프롬프트까지 납품한다. 기존 캡컷 프로젝트는 백업하고 요청 범위만 수정한다. 게시나 썸네일 생성은 요청 없이 실행하지 않는다.

## 기존 실행 자료 재사용
기존 에피소드의 검증된 스크립트·manifest·voice config를 우선한다. scripts/ 및 templates/는 인터페이스 참고 자료이며 언어·목소리·시간·스타일 기본값을 새 편에 자동 복사하지 않는다. 장면 계획은 기존 실행 형식과 맞춰 작성한다.
채널 설정 파일 부재를 새 채널 인터뷰 사유로 삼지 않는다. 로컬/클라우드 작성 위치와 영상 생성 방법을 구분한다. 비용·모델·계정은 작업 시 실제 상태를 확인한다.
