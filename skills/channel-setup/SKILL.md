# 채널 설정

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

Cheezon은 이미 제작 중인 채널이다. CHANNEL.md 유무만으로 새 채널 인터뷰를 시작하지 않는다. 기존 에피소드·인수인계·최신 사용자 지시로 설정을 확인한다. 다른 새 채널은 사용자가 제공한 목적과 시청자·언어·제작 범위에 맞춰 구성하고 Cheezon의 서사 비율·목소리·도구를 자동 복사하지 않는다.
