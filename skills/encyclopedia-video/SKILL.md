# 현재 영상 진입점

현재 기준은 프로젝트 [CHANNEL.md](../../../CHANNEL.md)와 [cheezon-video](../cheezon-video/SKILL.md)다. 과거 측정값·예시·템플릿은 참고 자료이며 현재 제작 규칙을 덮지 않는다.

기존 camera_moves.md는 카메라 용어 참고용이다. 클립당 한 무빙 또는 고정 구도를 사용하며 변형·모프가 실제 구조를 바꾸지 않게 한다. 예전 저채도 클레이·사람 전면 금지·재작업 전면 금지 규칙은 현재 Cheezon 규칙이 아니다.
